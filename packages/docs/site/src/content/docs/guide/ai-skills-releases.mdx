## 支持能力

| 能力分类 | 支持内容 |
| --- | --- |
| 页面能力 | 数据列表和卡片列表；<br />创建表单和编辑表单；<br />以信息展示为主的基础详情页。 |
| 交互能力 | 本地搜索和轻量快捷筛选；<br />卡片列表当前结果内的多选、全选和本地批量操作；<br />行操作、卡片操作和危险操作确认。 |
| 页面体验 | Light / Dark 基础规则；<br />响应式布局基础规则；<br />基础无障碍支持。 |
| 企业系统框架 | 常规后台页默认使用 DesignKit 标准顶部导航和可折叠侧边菜单；支持全局 Light / Dark 切换。 |
| AI 生成能力 | 根据需求自动选择已批准的页面模板；<br />自动查找并参考对应的 Golden Example；<br />使用真实 DesignKit 组件，而不是自行模仿样式；<br />遵循模板结构并执行基础质量检查；<br />使用固定 Runtime、单 HTML Demo 和本地 Mock。 |

其中主题、响应式、可访问性和视觉一致性仍需对每个生成页面实际验证；没有检查证据时不能标记为已通过。

## 当前暂不支持

以下项目明确不属于当前产品经理 Starter：

- Dashboard；
- Result Page；
- 自定义导航体系 / Navigation Shell 工程能力；
- 动态权限菜单、真实路由与权限配置、后端驱动导航；
- React/Vue 工程与组件 API 集成；
- 真实 Export；
- 真实后端/API、权限系统、上传和生产部署；
- Capability Registry 中标记为 `OUT` 或未登记的能力。
