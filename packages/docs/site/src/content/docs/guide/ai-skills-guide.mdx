## 什么是 DesignKit Starter

DesignKit Starter 是面向产品经理和非开发者的 AI 设计协作启动包。它提供固定 Runtime、页面模板、Capability Registry、Golden Example、设计规则和验证知识，帮助 AI 在已确认的范围内输出单个 HTML Demo。

Starter 适合产品评审、页面探索和交互验证，不是 React/Vue 工程包，也不负责组件 API 集成、真实后端接入或生产部署。
