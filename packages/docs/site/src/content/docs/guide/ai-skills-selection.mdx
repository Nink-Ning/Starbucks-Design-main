选择启动包时，先看你希望 AI 交付什么，而不是先看版本号。

<div class="sb-ai-skill-page-marker" aria-hidden="true"></div>

## 选择方法

| 你的目标 | 建议入口 | 当前状态 |
| --- | --- | --- |
| 用自然语言生成页面方案和单 HTML Demo | [产品经理启动包](../ai-skills-releases/) | 可用，当前推荐 V1-r2 |
| 进行产品评审、页面探索或本地交互验证 | [产品经理启动包](../ai-skills-releases/) | 可用 |
| 获取 React/Vue 工程、组件 API 或工程配置 | [前端开发启动包](../ai-skills-developer/) | 即将开放，当前无下载 |
| 查看所有角色包及维护状态 | [启动包总览](../ai-skills-starters/) | 可用 |

## 产品经理 / 非开发者

如果你需要的是页面方案、HTML Demo、模板选择或产品评审，请使用产品经理启动包。它使用固定 Runtime 和本地 Mock，不需要 React/Vue 工程环境。

当前推荐版本是 V1-r2。R2 重点增强模板保真、组件绑定和验证证据，没有扩展到真实后端、真实导出或生产工程。

## 前端开发者

前端开发启动包仍在建设中，当前没有可下载 ZIP，也没有已发布的工程能力承诺。React/Vue 工程、组件 API 集成和生产配置不能作为产品经理 Starter 的能力使用。

如果你当前只是查阅组件和页面模板，可继续使用现有 Docs；如果你需要角色化的开发启动包，请关注[前端开发启动包](../ai-skills-developer/)页面的后续状态。

## 仍然不确定时

从[启动包总览](../ai-skills-starters/)开始。先选择角色，再进入相应启动包页面查看当前能力、边界和版本历史。
