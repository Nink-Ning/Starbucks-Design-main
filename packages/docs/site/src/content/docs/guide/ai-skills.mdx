Starbucks UI 为 AI 编程助手（如 Claude Code）提供了 4 个 Skill 包，帮助 AI 在生成 React / Vue 页面时准确使用组件 API 与星巴克品牌主题。下载后按各自工具的 Skill 安装方式加载即可。

## 开发者版（含完整组件 API）

面向已有 Node.js / npm 开发环境的项目开发，覆盖全部组件的完整属性、事件、代码示例与最佳实践。

- [starbucks-design-react.zip](/kning/starbucks-design-main/skills/starbucks-design-react.zip) — Starbucks UI React 组件库（`@sbux/starbucks-design-react`）参考。当用户要求搭建页面、编写前端代码、开发 Web 应用或仪表盘、实现任意 React 界面时使用，覆盖全部 70 个组件的完整 API、代码示例、引入方式、主题、国际化、布局、表单、表格、弹窗、导航、数据录入、数据展示、反馈、响应式设计与最佳实践。
- [starbucks-design-vue.zip](/kning/starbucks-design-main/skills/starbucks-design-vue.zip) — Starbucks UI Vue 组件库参考，面向 Vue 3 与 `@sbux/starbucks-design-vue`。当用户要求构建 Vue 页面、创建 Vue UI、使用 Starbucks Vue 编写前端代码、开发 Vue 仪表盘或应用，或提到 Starbucks UI Vue、`a-button`、`a-table`、`a-form` 等任意 Starbucks Vue 组件名时使用，覆盖安装、全局注册、按需加载、主题、国际化、Composition API 约定、组件属性 / 事件 / 插槽、表单、表格、弹窗、导航、数据录入、数据展示、反馈和响应式布局。

## 零环境预览版（生成单文件 HTML）

面向没有前端开发环境的产品经理、设计师等用户，零安装、零编译，通过 CDN 加载 UMD 版本，生成一个 `.html` 文件双击即可预览。

- [starbucks-design-react-preview.zip](/kning/starbucks-design-main/skills/starbucks-design-react-preview.zip) — 星巴克 React 页面可视化搭建，零环境、零编译，生成一个 HTML 文件双击即可预览。当用户要求「搭一个页面」「做一个表单」「画一个后台」「预览一下」「我没有开发环境」时使用，覆盖 Button、Table、Form、Modal、Select、Input、DatePicker、Layout、Menu、Card、Tabs、Alert、Drawer、Pagination、Steps 等全部组件，星巴克品牌绿主题自动注入，无需手动配置。
- [starbucks-design-vue-preview.zip](/kning/starbucks-design-main/skills/starbucks-design-vue-preview.zip) — 星巴克 Vue 页面可视化搭建，零环境、零编译，生成一个 HTML 文件双击即可预览。面向产品经理、设计师等无前端开发环境的用户，同样的使用场景下触发，覆盖全部组件，使用 `a-` 前缀（`a-button`、`a-table` 等），星巴克品牌绿主题自动注入，无需手动配置。
