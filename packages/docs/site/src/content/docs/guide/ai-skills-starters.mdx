## 产品经理启动包能力

- **标准应用框架**：固定的 Top Navigation、Side Navigation、展开/收起关系、响应式 viewport 布局与 Light / Dark；
- **页面模板**：Basic List、Card List、Basic Detail、Basic Form、Grouped Form、Step Form、Drawer Form；
- **页面层级**：Level 1 标题、Level 2 返回与标题、Depth ≥ 3 面包屑；
- **标准组件组合**：Toolbar、Table actions、Link、Breadcrumb、Steps、Drawer 与 Form controls。

这些能力用于快速生成标准页面和连贯的静态多页面演示，不等同于自定义导航架构、真实 Router、权限路由或完整前端工程。

## 如何管理版本

产品经理启动包页面统一提供：

- 当前推荐版本和下载入口；
- 当前支持与暂不支持的能力；
- V1、V1-r1、V1-r2、V1-r3 的能力对比；
- 按时间倒序排列的版本历史和可信校验信息。

新版本发布时，应更新对应启动包页面，而不是在侧栏增加一个新的版本菜单项。
