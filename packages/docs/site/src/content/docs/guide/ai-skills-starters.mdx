## 如何管理版本

产品经理启动包页面统一提供：

- 当前推荐版本和下载入口；
- 当前支持与暂不支持的能力；
- V1、V1-r1、V1-r2 的能力对比；
- 按时间倒序排列的版本历史和可信校验信息。

新版本发布时，应更新对应启动包页面，而不是在侧栏增加一个新的版本菜单项。
