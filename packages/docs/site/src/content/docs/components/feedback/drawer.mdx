触发命令后，从屏幕一侧滑出的抽屉式的面板。

## 基本用法

点击触发按钮抽屉从右侧滑出，点击遮罩区关闭。

<FrameworkBlock framework="react">
抽屉的显示与隐藏通过 `visible` 属性控制，配合 `onOk` / `onCancel` 回调更新状态。
</FrameworkBlock>

<FrameworkBlock framework="vue">
抽屉的显示与隐藏通过 `v-model:visible` 双向绑定，或通过 `default-visible` 指定默认值（非受控）。
</FrameworkBlock>

<Demo name="drawer/basic" />

## 抽屉位置

自定义位置，点击触发按钮抽屉从相应的位置滑出。可通过 `placement` 设置抽屉弹出的方向（`top`、`right`、`bottom`、`left`）。

<Demo name="drawer/drawer-position" />

### `<drawer>` 全局方法

Drawer 提供的全局方法，可以通过以下三种方法使用：

1. 通过 `this.$drawer` 调用
2. 在 Composition API 中，通过 `getCurrentInstance().appContext.config.globalProperties.$drawer` 调用
3. 导入 Drawer，通过 Drawer 本身调用

当通过 import 方式使用时，组件没有办法获取当前的 Vue Context，如 i18n 或 route 等注入在 AppContext 上的内容无法在内部使用，需要在调用时手动传入 AppContext，或者为组件全局指定 AppContext

```ts
import { createApp } from 'vue'
import { Drawer } from '@sbux/starbucks-design-vue';

const app = createApp(App);
Drawer._context = app._context;
```
