仅允许输入数字格式的输入框。

## 基本用法

通过鼠标或者键盘输入范围内的标准数值。

<FrameworkBlock framework="react">
数字输入框的值可以通过 `value` 与 `onChange` 受控使用，或通过 `defaultValue` 指定默认值（非受控）。
</FrameworkBlock>

<FrameworkBlock framework="vue">
数字输入框的值可以通过 `v-model`（即 `model-value` 配合 `change` / `input` 事件）双向绑定，或通过 `default-value` 指定默认值（非受控）。
</FrameworkBlock>

<Demo name="input-number/basic" />

## v-model 的触发事件

<FrameworkBlock framework="vue">

数字输入框默认在 blur 或者按下 Enter 时会修改绑定的值，通过设置属性 `model-event="input"` 让组件在输入时修改绑定的值。

注意：在此模式下，输入时的值会超出设置的 min/max，组件会在失焦时修正值的大小。

</FrameworkBlock>

<Demo name="input-number/v-model-trigger" />

## 按钮模式

指定 `mode` 为 `button` 来使用带按钮的数字输入框。

<Demo name="input-number/button-mode" />

## 四种尺寸

<FrameworkBlock framework="react">
设置 `size` 可以使用四种尺寸（`mini`、`small`、`default`、`large`）的数字输入框。高度分别对应 `24px`、`28px`、`32px`、`36px`。
</FrameworkBlock>

<FrameworkBlock framework="vue">
设置 `size` 可以使用四种尺寸（`mini`、`small`、`medium`、`large`）的数字输入框。高度分别对应 `24px`、`28px`、`32px`、`36px`。
</FrameworkBlock>

<Demo name="input-number/four-sizes" />

## 精度和步长

通过 `precision` 来设置数字精度。当 `precision` 小于 `step` 的小数位时，精度取 `step` 的小数个数。

<Demo name="input-number/precision-step" />

## 格式化展示值

通过 `formatter` 和 `parser` 配合使用可以定义输入框展示值。

<FrameworkBlock framework="react">
通过 `formatter` 中的 `userTyping` 参数，判断是否正在输入，可以延迟显示 `formatter` 后的值。
</FrameworkBlock>

<Demo name="input-number/format-display" />

## 前缀与后缀

<FrameworkBlock framework="react">
通过 `prefix` 和 `suffix` 属性来在输入框内添加前缀和后缀。
</FrameworkBlock>

<FrameworkBlock framework="vue">
通过指定 `prefix` 和 `suffix` 插槽来在输入框内添加前缀和后缀。

## 高精度

<FrameworkBlock framework="react">
通过 `strictMode` 开启严格模式以支持更高精度，`onChange` 此时将会返回字符串。

### InputNumberValueChangeReason

```js
// 造成输入框值改变的原因：用户输入、增加、减少、超出范围值修正
export type InputNumberValueChangeReason =
  | "manual"
  | "increase"
  | "decrease"
  | "outOfRange";
```
