标签输入。用来输入标签。

## 基本用法

标签输入框的基本用法。

<FrameworkBlock framework="react">
标签的值可以通过 `value` 与 `onChange` 受控使用，或通过 `defaultValue` 指定默认值（非受控）。
</FrameworkBlock>

<FrameworkBlock framework="vue">
标签的值可以通过 `v-model`（即 `model-value` 配合 `change` 事件）双向绑定，或通过 `default-value` 指定默认值（非受控）。
</FrameworkBlock>

<Demo name="input-tag/basic" />

## 输入框状态

输入框有禁用、只读和错误三种状态。

<FrameworkBlock framework="react">
分别通过 `disabled`、`readOnly` 与 `status="error"` 设置。
</FrameworkBlock>

<FrameworkBlock framework="vue">
分别通过 `disabled`、`readonly` 与 `error` 设置。
</FrameworkBlock>

<Demo name="input-tag/input-status" />

## 前缀/前置标签/后置标签

<FrameworkBlock framework="react">
通过 `prefix` 添加前缀，通过 `addBefore`、`addAfter` 在输入框前后添加前置/后置标签。
</FrameworkBlock>

<Demo name="input-tag/prefix-addon" />

## 输入框尺寸

<FrameworkBlock framework="react">
输入框分为 `mini`、`small`、`default`、`large` 四种尺寸，通过 `size` 指定，默认为 `default`。
</FrameworkBlock>

<FrameworkBlock framework="vue">
输入框分为 `mini`、`small`、`medium`、`large` 四种尺寸，通过 `size` 指定，默认为 `medium`。
</FrameworkBlock>

<Demo name="input-tag/input-size" />

## 最多展示标签数量

<FrameworkBlock framework="react">
通过 `maxTagCount` 设置最多展示的标签数，`maxTagCount.render` 自定义 `+x` 部分的节点内容。
</FrameworkBlock>

<FrameworkBlock framework="vue">
通过 `max-tag-count` 设置最多展示的标签数量，`0` 表示不限制。
</FrameworkBlock>

<Demo name="input-tag/max-tags" />

## 响应式显示Tag

<FrameworkBlock framework="react">

通过 `maxTagCount="responsive"` 设置根据容器尺寸动态显示 Tag 数。会监听所有 Tag 及容器的尺寸变化，所以在标签数较多时不建议使用，可能存在性能问题。此时拖拽和动画效果不可用。

</FrameworkBlock>

<Demo name="input-tag/responsive-tag" />

### `<input-tag>` Events

|事件名|描述|参数|
|---|---|---|
|change|值发生改变时触发|value: `(string \| number \| TagData)[]`<br/>ev: `Event`|
|input-value-change|输入值发生改变时触发|inputValue: `string`<br/>ev: `Event`|
|press-enter|按下回车键时触发|inputValue: `string`<br/>ev: `KeyboardEvent`|
|remove|点击标签的删除按钮时触发|removed: `string \| number`<br/>ev: `Event`|
|clear|点击清除按钮时触发|ev: `MouseEvent`|
|focus|输入框获取焦点时触发|ev: `FocusEvent`|
|blur|输入框失去焦点时触发|ev: `FocusEvent`|

### `<input-tag>` Methods
