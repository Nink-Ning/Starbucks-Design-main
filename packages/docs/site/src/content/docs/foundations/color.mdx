色彩系统以星巴克品牌绿为核心，配合成功、警告、错误三组功能色与一套中性色，构成完整的界面语义。每个色板点击即可复制色值。

## 品牌色

主色用于关键操作、选中态与品牌表达。围绕主色提供 hover / active / focus / disabled 及浅色变体，覆盖交互全流程。

/>
