间距以 **4px 为基准单位**逐级递增，控制元素间的呼吸感与信息分组。统一的间距阶梯让不同页面保持一致的节奏。点击任一档可复制其像素值。

## 使用建议

- **以 4 的倍数取值**，避免出现 5px、7px 这类破坏节奏的间距。
- **元素内**（图标与文字、标签内边距）用 4–8；**组件内边距**用 12–16；**区块之间**用 24–32；**页面级留白**用 48–72。
- 同一层级的元素使用**相同间距**，靠间距的疏密表达信息的分组关系——关系近的靠得近，关系远的隔得开。
