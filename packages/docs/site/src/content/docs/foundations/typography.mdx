排版建立信息的层级与节奏。中文正文使用 **Noto Sans SC**，西文使用 **Poppins**，数字使用 **Roboto**（等宽对齐更利于数据展示）。字号与行高成组定义，确保跨场景的一致节奏。

## 字体

| 用途 | 字体 |
| --- | --- |
| 中文 | Noto Sans SC |
| 西文 | Poppins |
| 数字 | Roboto |

## 使用建议

- **标题**用 Medium 字重拉开层级，正文统一 Regular，避免通篇加粗削弱重点。
- **行高**已随字号成组定义，直接套用即可，无需逐处微调。
- **数字**（价格、统计、表格数值）使用 Roboto 并开启等宽数字（`tabular-nums`），保证纵向对齐。
