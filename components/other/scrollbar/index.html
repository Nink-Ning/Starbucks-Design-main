滚动条 Scrollbar

仅 Vue 提供

该组件目前仅提供 Vue 版本。

用于替换浏览器默认滚动条样式。

基本用法

滚动条组件基本用法。scrollbar 的默认插槽需要唯一的子元素。

该组件暂无 React 示例
Show code
代码示例 
<template>
  <Scrollbar style="height:200px;overflow: auto;">
    <div
      style="height: 2000px;width: 2000px; background-color: var(--color-primary-light-4);"
      >Content</div
    >
  </Scrollbar>
</template>

滚动条类型

设置 type 属性改变滚动条类型，track 类型会显示滚动条轨道。

该组件暂无 React 示例
Show code
代码示例 
<template>
  <Scrollbar type="track" style="height:200px;overflow: auto;">
    <div
      style="height: 2000px;width: 2000px; background-color: var(--color-primary-light-4);"
      >Content</div
    >
  </Scrollbar>
</template>
