# Starbucks Design

## AI-Native Enterprise Design System powered by Codex

Starbucks Design 是一个面向企业级 B 端产品设计与开发协作的 AI-Native Design System 实践项目。

项目基于 React、Vue、Docusaurus 和 Codex 工作流建设，将设计规范、组件资产、业务组件、页面模板以及 Design Skills 进行结构化沉淀。

通过 AI Agent 理解设计规则和工程约束，辅助完成组件生成、页面构建、文档维护以及设计质量验证。

# 🤖 AI Workflow

Starbucks Design 通过 Codex 和 AI Agent，将设计经验、工程规则和业务资产转化为可执行 AI 工作流。


## Workflow Overview
Design Knowledge
    ↓
Design Skills
    ↓
AI Agent Reasoning
    ↓
Component / Page Generation
    ↓
Design Quality Validation


## Design Knowledge

沉淀企业设计资产：

- Design Language
- Component Specifications
- Business Patterns
- Design Decisions
- Engineering Rules


## Design Skills

将设计经验转化为 AI 可理解规则：

- Global Skills
- Architecture Rules
- Design Decision Rules
- Task Routing Rules


## AI Agent Capability

AI Agent 能够：

- 理解企业设计语言
- 遵循设计决策规则
- 生成符合规范的产品页面
- 辅助组件开发
- 提升研发交付质量
